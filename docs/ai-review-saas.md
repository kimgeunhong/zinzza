# AI 자동 영상 리뷰 편집 SaaS 기획 산출물

## 1. 서비스 개요
- **서비스 명(가칭)**: Auto Review Studio
- **핵심 목표**: 유튜브/틱톡 리뷰 영상을 저작권 안전 기준에 맞춰 최소 인용으로 자동 편집하여 수익화(YPP/Creator Rewards)를 지원
- **대상 사용자**: 영상 편집을 간소화하고 싶은 초보 및 중급 리뷰어, 숏폼 크리에이터
- **핵심 가치 제안**: 작업 시간 절감, 저작권 리스크 최소화, 플랫폼 수익화 가능성 극대화

## 2. 주요 사용자 여정
1. 회원 가입 및 온보딩: 관심 카테고리(영화/드라마/게임 등), 수익화 목표 입력
2. 프로젝트 생성: 원본 영상/오디오 또는 스크립트 업로드
3. AI 자동 편집 및 저작권 안전 진단
4. 결과물 미리보기, 템플릿 및 세부 설정 조정
5. 플랫폼별 렌더링 및 자막/챕터 출력
6. 대시보드에서 성과 지표 확인 및 후속 작업 관리

## 3. 와이어프레임 개요

### 3.1 랜딩 & 온보딩
- **Hero 섹션**: "저작권 안전한 AI 리뷰 편집으로 수익화까지" 헤드라인, CTA 버튼(무료로 시작하기)
- **핵심 가치 블록**: 시간 절약, 저작권 보호, 수익화 지원 3열 카드
- **데모 비디오/이미지**: 텍스트 기반 편집 인터페이스 미리보기
- **플랜 요약 섹션**: 무료/스탠다드/프로 비교 테이블
- **온보딩 모달**: 업로드 유형 선택, 채널 목표 체크리스트

### 3.2 프로젝트 대시보드
- 상단: 최근 프로젝트, 렌더링 큐 상태, 저작권 경고 알림 배너
- 중앙 카드 그리드: 프로젝트 타일(썸네일, 상태, 인용 비율 게이지)
- 측면 사이드바: 템플릿 라이브러리, 가이드 문서, 고객 지원 링크

### 3.3 프로젝트 업로드 & 분석 화면
- **좌측 패널**: 업로드 위저드(영상/오디오/텍스트), 언어 옵션, 업로드 진행률
- **중앙**: 전사 요약, AI 진단 상태(필러 워드 감지, 침묵 구간 표시)
- **우측**: 저작권 안전 지표(클립 길이 제한, 전체 인용 비율, 워터마크 옵션)
- 하단: "AI 자동 편집 실행" CTA 버튼

### 3.4 AI 텍스트 기반 편집기 (핵심 화면)
- **상단 바**: 프로젝트 이름, 버전 관리, 플랫폼 비율(16:9 / 9:16) 토글
- **중앙 좌측**: 텍스트 전사 에디터 (문단 단위 = 컷). 문장 클릭 시 프리뷰 싱크
  - 필러 워드 삭제 제안 토글
  - 하이라이트 추출(숏폼 변환) 버튼
- **중앙 우측**: 영상 프리뷰, 컷 타임라인, 저작권 안전 게이지
- **우측 패널**: 템플릿 스타일, BGM 추천, B-roll 제안 리스트
- **하단**: 편집 히스토리/Undo-Redo, 협업 코멘트, 자동 저장 상태

### 3.5 템플릿 & 자산 라이브러리
- 카테고리 탭(영화 리뷰, 게임 해설, 제품 언박싱)
- 템플릿 카드: 프리뷰 썸네일, 적용 버튼, 기본 설정 요약(폰트, BGM, 인용 한도)
- AI 추천 B-roll 스톡: 검색 창, 사용권(저작권 프리) 배지, 삽입 버튼

### 3.6 렌더링 & 내보내기
- **좌측 패널**: 출력 포맷 선택(YouTube 16:9, TikTok 9:16), 해상도 옵션(1080p/4K)
- **중앙**: 렌더링 큐 상태, 예상 시간, GPU 사용률
- **우측**: 자막(.SRT) 다운로드, 챕터 자동 생성 확인, 플랫폼별 메타데이터 추천
- 저작권 안전 최종 체크: 인용 비율, 워터마크 적용 여부, 라우드니스 준수 알림

### 3.7 계정 & 결제 관리
- 플랜 업그레이드 카드(무료/스탠다드/프로 비교)
- 결제 히스토리, 사용량(월 렌더링 시간, 스톡 에셋 사용량) 그래프
- 팀 멤버 초대, 권한 설정

## 4. 핵심 개발 태스크 리스트

### 4.1 프론트엔드
- Next.js 또는 React 기반 SPA/MPA 구성, 다크/라이트 테마 토글 구현
- 텍스트 기반 편집기 컴포넌트 개발: 전사 텍스트와 영상 프리뷰 싱크, 컷 단위 편집, 필터 적용 UI
- 템플릿/에셋 라이브러리 UI 구축: 검색, 필터, 프리뷰, 적용 인터랙션
- 렌더링 큐 모니터링 대시보드, 상태 알림 컴포넌트 개발
- 저작권 안전 경고 배너 및 게이지 시각화(Progress Circle, 색상 경고 단계)

### 4.2 백엔드 & API
- 사용자 인증/결제 연동(Stripe 등) 및 플랜 권한 관리
- 업로드 파이프라인: 대용량 영상/오디오 파일 업로드, 클라우드 스토리지 연동, 업로드 상태 웹훅
- 전사/분석 결과, 편집 타임라인, 렌더링 프로필을 저장하는 프로젝트 데이터 모델 설계
- 렌더링 작업 큐 관리(예: AWS Batch, FFmpeg 기반 워커) 및 상태 트래킹 API
- 저작권 준수 규칙 엔진: 클립 길이 제한, 총 인용 비율 계산, 경고/차단 로직

### 4.3 AI/ML 파이프라인
- 음성 전사 모델 연동(Whisper API 등) 및 필러 워드/침묵 감지 후처리
- 텍스트 기반 컷 분할 알고리즘: 문장 단위 컷 생성, 점프컷 옵션, 하이라이트 추출(요약) 모델
- 인용 최소화 가이드 AI: 원본 영상 메타데이터 비교, 변형성 강화 필터 제안 로직
- 키워드 기반 B-roll 추천 모델: 저작권 프리 스톡 데이터베이스와 매칭
- 오디오 믹싱 자동화: 보이스/BGM 라우드니스 분석 및 자동 볼륨 조절(−14 LUFS 목표)

### 4.4 인프라 & DevOps
- 서버리스/컨테이너 기반 배포 전략(Cloud Run, ECS, Kubernetes 등) 수립
- 렌더링 GPU 노드 및 AI 추론 서버 분리, 오토스케일링 정책 정의
- 모니터링/로깅/알림 스택 구축(Prometheus, Grafana, Sentry)
- CDN 기반 결과물 전달(CloudFront 등) 및 만료 정책 설정
- 백업 및 DR(Disaster Recovery) 계획 수립, 개인정보/콘텐츠 암호화 정책 마련

### 4.5 법무/운영 지원
- 저작권 안전 가이드라인 문서화 및 UI 내 툴팁/튜토리얼 제공
- YPP/Creator Rewards 정책 업데이트 모니터링, 자동 알림 시스템 구축
- 고객 지원 워크플로우: 문의 티켓, 리포트 관리, FAQ/헬프센터 콘텐츠 작성
